Jura Error 1: thermoblock sensor fault

Error 1 : Coffee thermoblock temperature sensor fault (S/X/J/Z family); damaged sensor on F/E80.

Réponse rapide. The control board cannot get a sane reading from the temperature sensor on the coffee thermoblock. A cold machine straight from a cold car or garage can trigger it; otherwise the sensor, its cable, or the thermal-fuse cords that feed the thermoblock have failed.
Pièce en causecoffee thermoblock NTC sensor
Gravitémoyenne
Difficultédifficile
Quand l’erreur survientà tout moment

Comment corriger Error 1

  1. Unplug for five minutes, let the machine sit at room temperature for an hour if it has been cold, and restart.
  2. If it clears, it was temperature. If it returns instantly on a warm machine, the sensor circuit is open.
  3. Opening a Jura needs the oval-head (Torx-Plus security) driver. With the cover off, check the sensor plug on the thermoblock and the thermal-fuse cords for a broken link.
  4. Replace the NTC sensor (cheap) and the fuse cords together; if the thermoblock itself is scaled solid, replace it.

Quand s’arrêter et appeler un réparateur

Jura cases are held with security screws and the thermoblocks carry mains voltage. If you are not set up for that, this is a bench repair.

Ce que ça coûte

Pièces : Genuine Jura NTC sensor about $25 to $40; thermal-fuse cord set $15 to $30; a thermoblock $90 to $180.

Main-d’œuvre : Le service constructeur hors garantie pour un automatique se chiffre généralement entre 250 et 500 € retour inclus ; un réparateur indépendant est souvent plus avantageux pour une seule pièce.

Vaut la réparation ? Yes on S, Z, GIGA and newer E-series; on a 10-year-old Impressa weigh the quote against a refurbished unit.

Questions fréquentes

Que signifie Error 1 sur la Jura ?

Coffee thermoblock temperature sensor fault (S/X/J/Z family); damaged sensor on F/E80. The control board cannot get a sane reading from the temperature sensor on the coffee thermoblock. A cold machine straight from a cold car or garage can trigger it; otherwise the sensor, its cable, or the thermal-fuse cords that feed the thermoblock have failed.

Peut-on réparer Error 1 soi-même ?

Difficulté : difficile. Unplug for five minutes, let the machine sit at room temperature for an hour if it has been cold, and restart. If it clears, it was temperature. If it returns instantly on a warm machine, the sensor circuit is open.

Error 1 au démarrage ou en cours d’utilisation ?

Sur les Jura, Error 1 survient à tout moment. Aucun schéma fiable : prenez chaque apparition au sérieux.

Peut-on continuer à utiliser la machine avec Error 1 affiché ?

On peut généralement terminer sa boisson, mais n’ignorez pas le code : la panne ne se guérit pas seule. Commencez par les contrôles gratuits.

Error 1 disparaîtra-t-il tout seul ?

Rarement. Un reset vaut un essai, mais un Error 1 classé « difficile » signifie presque toujours une pièce à remplacer.

Combien de temps prend la réparation ?

Pour la plupart, c’est un travail d’atelier — démontage, tests et remontage sont le gros du travail, pas la pièce.
