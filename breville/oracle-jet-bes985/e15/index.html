Breville / Sage Oracle Jet E15: electrical safety protection triggered

E15 : Zero-cross electrical signal not detected during manual operation.

Réponse rapide. The machine detected an electrical fault: leakage current to ground, an unexpected mains waveform, or a heater drawing power when it should not. Water on a heating element or the power board is the everyday cause. This is the code that also trips the GFCI / RCD in your kitchen.
Pièce en causemains electrical / triac board
Gravitéélevée
Difficultédéconseillé
Quand l’erreur survientpendant l’extraction ou la vapeur

Comment corriger E15

  1. Unplug. Do not keep resetting the breaker; each trip is the machine telling you current is going where it should not.
  2. Let the machine dry for 24 hours somewhere warm. A machine that has been descaled or has a slow leak often has water around the element terminals.
  3. Check the mains cable and plug for damage and try a different socket on a different circuit.
  4. If it runs after drying, find and fix the leak (o-rings, hoses, boiler fittings) or it will return.
  5. If it trips again dry, the element insulation or the power board has failed. That is a technician job.

Quand s’arrêter et appeler un réparateur

This is a mains-electricity fault. Unless you are competent with live testing, hand it to a repairer.

Ce que ça coûte

Pièces : Triac / power board $80 to $150; heating element $60 to $150.

Main-d’œuvre : Le service constructeur hors garantie pour un automatique se chiffre généralement entre 250 et 500 € retour inclus ; un réparateur indépendant est souvent plus avantageux pour une seule pièce.

Vaut la réparation ? Drying out: yes. Element or board on an old machine: get a quote first.

Consulter le journal des erreurs

Open Settings on the touch screen, then About the Machine, then Software version. On that screen tap each bottom corner of the screen several times. Go back to About the Machine and a new Service center mode entry appears. Open it to view the error log.

Effacez le journal après réparation pour vérifier que la panne a vraiment disparu.
