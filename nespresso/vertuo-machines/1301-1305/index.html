Nespresso Vertuo 1301-1305: défaut détartrage ou capteur capsule

1301-1305 : Famille de défauts détartrage/capteur de capsule sur les Vertuo connectées — machine coincée en mode détartrage ou capsule mal lue.

Réponse rapide. Nespresso ne publie pas la table des codes 1300 ; les retours d'utilisateurs relient systématiquement le 1301 à une machine coincée en mode détartrage et à un capteur de capsule qui lit mal, les codes voisins traitant de la même famille. La séquence officielle est la même dans tous les cas : réinitialisation d'usine, puis un cycle de détartrage complet, puis nettoyage de la fenêtre de lecture.

Comment corriger 1301-1305

  1. Réinitialisation d’usine (procédure officielle Vertuo) : manche en position DÉVERROUILLÉE, appuyez 5 fois sur le bouton en moins de 3 secondes — il clignote 5 fois en orange pour confirmer.
  2. Lancez un détartrage complet avec le détartrant Nespresso et laissez-le finir sans interruption : un détartrage annulé est la façon classique de rester coincé dans le mode.
  3. Retirez le porte-capsule et essuyez la fenêtre de lecture et la tête pour que le capteur lise le code de la capsule.
  4. Videz et remplissez le bac, puis retestez avec une capsule neuve.
  5. Si le code persiste après réinitialisation, détartrage et nettoyage : contactez l’assistance Nespresso — les Vertuo sont habituellement échangées sous garantie plutôt que réparées.

Quand s’arrêter et appeler un réparateur

Rien de dangereux — ne forcez juste pas la tête fermée sur une capsule.

Ce que ça coûte

Pièces : Le plus souvent 0 € — détartrant 15 € ; Nespresso échange les machines défectueuses.

Main-d’œuvre : Le service constructeur hors garantie pour un automatique se chiffre généralement entre 250 et 500 € retour inclus ; un réparateur indépendant est souvent plus avantageux pour une seule pièce.

Vaut la réparation ? Oui : la séquence réinit–détartrage–nettoyage règle la plupart des signalements.

1301-1305 au démarrage ou en cours d’utilisation ?

Sur les Nespresso Vertuo, 1301-1305 survient à tout moment. Ce moment est un indice utile pour cibler la cause.

Peut-on continuer à utiliser la machine avec 1301-1305 affiché ?

On peut généralement terminer sa boisson, mais n’ignorez pas le code : la panne ne se guérit pas seule. Commencez par les contrôles gratuits.

1301-1305 disparaîtra-t-il tout seul ?

Souvent, oui. La première étape (réinitialisation d’usine (procédure officielle vertuo) : manche en position déverrouillée, appuyez 5 fois sur le bouton en moins de 3 secondes — il clignote 5 fois en orange pour confirmer) débloque une partie des cas seule. Si le code revient aussitôt, la pièce est vraiment en cause.

Combien de temps prend la réparation ?

Quinze à trente minutes avec les outils de base, pièce en main.
