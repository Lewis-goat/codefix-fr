Codes d’erreur fours Samsung : la liste complète

Les fours et cuisinières Samsung répartissent leurs codes en trois familles : les codes C (surveillance de température et du ventilateur de refroidissement sur les cuisinières connectées récentes), les codes E (pannes de fonction du four) et les codes courts (panneau de commande : SE, tE, LE). Chaque code renvoie à une page qui commence par la réparation, avec la pièce, le coût et si ça vaut le coup.

Codes C : température et ventilateur

Ils apparaissent sur les cuisinières connectées des séries NE/NX récentes. Les trois que l’on rencontre vraiment : C-21 (coupure de surchauffe du four — sonde), C-24 (montée en température rapide près de la zone de ventilation — circulation d’air ou thermistance) et C-F2 (défaut de retour du ventilateur de refroidissement).

Premiers gestes pour tout code four Samsung

  1. Coupez le courant au disjoncteur pendant 5 minutes — les cartes Samsung conservent le code jusqu’à une réinitialisation franche ; un code qui revient après coupure est réel.
  2. Notez le code exact avant qu’il ne s’efface — la partie lettrée identifie la famille et cible la pièce immédiatement.
  3. Les codes de la famille température (C-21, C-24, E-2x) commencent par la sonde de cavité : environ 1 080 ohms à température ambiante au multimètre, c’est sain.
  4. Les codes de surchauffe imposent d’arrêter la cuisson jusqu’à vérification — un four qui surchauffe vraiment est un risque d’incendie, pas un désagrément.

Samsung publie une liste officielle de codes par gamme sur le support samsung.com ; cette page compile les codes réellement rencontrés par les propriétaires avec les réparations réellement appliquées par les réparateurs. Les suffixes de modèle (NE58*/NX60*) peuvent ajouter des codes — cherchez le code affiché plus le numéro de modèle pour ce qui n’est pas listé.
