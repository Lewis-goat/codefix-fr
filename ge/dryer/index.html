Codes d’erreur GE Appliances sèche-linge

Les sèche-linges GE affichent des codes E pour les sondes NTC, l’interrupteur de porte, le tachymètre du moteur et le panneau de commande. Un même code peut avoir des significations différentes selon les millésimes ; chaque page précise laquelle.

Consulter le journal des erreurs

Sur les sèche-linges GE plus récents (GTD/GFD à partir de 2016), machine éteinte, appuyez sur les boutons Signal et Temp pendant 5 secondes pour entrer en mode service ; la dernière erreur mémorisée s’affiche. Sur les modèles SmartHQ, l’application liste les codes mémorisés. Débrancher l’appareil pendant 5 minutes réinitialise la carte.

Les menus service sont destinés aux techniciens. Lire le journal est sans risque ; ne modifiez pas les valeurs d’étalonnage.
